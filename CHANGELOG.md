# Changelog

## 0.2.0

- Vortux can now download its own Wine (Kron4ek's builds) and winetricks, so a distro Wine isn't required.
  The requirements screen lets you choose, and the app screen lists everything that will be downloaded
  before you press the button.
- Menu entries now point at their icons by full path.
- Removed the retry that sent browser-style request headers; it never helped.

## 0.1.0

First version.

- Installer window with system check, app choice, progress and cancel
- Separate Wine prefix with DXVK and VKD3D-Proton
- Player and Studio menu entries with icons, and browser link handlers for both
- Manual file drop for Studio, whose download needs a logged-in session
- Settings: 3D background and animations on/off, repair, shortcuts to the install and logs folders
- Uninstall that removes everything Vortux created
